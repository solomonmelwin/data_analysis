# Business Performance Dashboard

## Overview
Interactive dashboard built using Python, SQL, Pandas, and Streamlit for analyzing business sales and profit trends.

## Features
- KPI cards
- Regional analysis
- Profit analysis
- Customer insights
- Interactive filters
- Business recommendations

## Tools Used
- Python
- Pandas
- SQL
- Streamlit
- Matplotlib

## Key Insights
- Q4 sales are strongest
- Some categories generate low profit despite high sales
- Top customers contribute major revenue

## How to Run
streamlit run app.py
