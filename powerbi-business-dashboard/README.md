# Power BI Business Dashboard

## Overview
Interactive business intelligence dashboard built using Power BI to analyze sales, profit, customer behavior, and regional performance.

---

## Features
- KPI cards
- Profit margin analysis
- Regional sales analysis
- Drill-through pages
- Dynamic filtering
- Executive summary insights
- Monthly sales trends

---

## Tools Used
- Power BI
- DAX
- Excel/CSV Dataset

---

## Key Insights
- West region generated highest sales
- Technology category performed strongest
- Q4 months consistently showed high revenue
- Central region had lower profitability
